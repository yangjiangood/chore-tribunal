# 方案 B：综艺战情室

## 1. 方案定位

### 核心概念

把产品做成一块 `家务赛事实时直播大屏`。  
不是“公告栏”，而是“节目现场”。

### 风格关键词

- 综艺舞台
- 实时赛况
- 高能排名
- 公开处刑
- 灯光感

### 适用判断

这套方案适合想把产品做得更“炸”、更有传播感的方向。

如果你的目标是：

- 一眼就觉得有趣
- 全家路过都想点一下
- AI 判决像主持人上场

那它会很对味。

## 2. 视觉方向

### 2.1 整体氛围

像 `大型综艺比分屏 + 游戏赛事 HUD + 家庭吐槽直播间`。

它比方案 A 更强烈、更年轻、更高刺激。

### 2.2 配色系统

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Stage Navy | `#0F172A` | 背景底色 |
| Signal Coral | `#FF5A36` | 主行动色、AI 裁判 |
| Acid Lime | `#B7F04A` | 正向反馈、上涨 |
| Electric Cyan | `#5ED8FF` | 中性动作、核心家务 |
| Arena Gold | `#F8C84A` | 冠军、奖章 |
| Spotlight White | `#F8FAFC` | 主文字 |
| Panel Steel | `#1E293B` | 卡片、面板 |

### 2.3 字体系统

| 角色 | 字体建议 | 用途 |
| --- | --- | --- |
| 标题 | `Sora` / `Space Grotesk` | 名次、巨型数据 |
| 正文 | `Noto Sans SC` | 中文信息 |
| 数字 | `Chakra Petch` / `IBM Plex Sans` | 分数、排名、时间 |

#### 气质

- 数字要有体育计分牌感
- 标题要带一点未来综艺舞台味
- 正文负责稳定信息密度

## 3. 首页主打卡面板

### 3.1 页面结构

建议采用 `中央主舞台 + 两侧信息翼`：

```text
┌──────────────────────────────────────────────────────────────────────┐
│ LOGO / 时钟 / 控制台 / 全屏 / 召唤AI                                  │
├───────────────┬───────────────────────────────┬──────────────────────┤
│ 排行榜翼       │ 成员主舞台列阵                  │ AI预告 / 今日热点翼   │
│ 1 妈妈 28      │ 妈妈  爸爸  小宝  外婆          │ 今晚判词预热          │
│ 2 小宝 16      │ 巨型分数 + 三档按钮 + 最近标签   │ 风格强度 7/10         │
│ 3 爸爸 12      │                                 │ 连冠/垫底走势         │
├──────────────────────────────────────────────────────────────────────┤
│ 滚动日志带 + 撤销 Toast + 周战报短句                                   │
└──────────────────────────────────────────────────────────────────────┘
```

### 3.2 核心组件语言

#### 成员卡

成员卡像 `选手计分台`：

- 头像是发光圆角牌
- 昵称像选手名牌
- 分数是超大七段式或机械式数字
- 三档按钮像节目按钮 / 冲刺按钮

#### 排行榜

左翼可以做成 `冲榜区`：

- 第 1 名有强灯条
- 名次变化时出现上下箭头
- 连冠成员旁边出现连胜标记

#### AI 预告翼

右翼可以承接：

- 今日最惨成员
- 本周可能被点名事项
- 当前人设
- 毒舌强度

## 4. 标签面板

### 4.1 形态

使用 `舞台浮窗 + 赛道按钮组`。

点击 `+3 核心家务` 后，面板从成员卡前方翻出，像一个节目答题板。

### 4.2 标签展示

- 最近使用放第一排
- 高频标签做大按钮
- 低频标签折叠到“全部事项”

### 4.3 反馈

- 点选标签后，舞台灯光从该成员卡下方扫过
- 同时日志带刷新

## 5. AI 判决弹窗

### 5.1 出场方式

这套方案的 AI 判决弹窗应做成 `主持人播报面板`：

- 先压暗背景
- 再从中间升起一个发光屏
- 标题区像节目口播条
- 正文分块滚入

### 5.2 风格强化

顶部应显式展示：

- 人设模式
- 毒舌强度
- 本周重点罪状数量

### 5.3 文案呈现

建议用大字号短句分屏出现，而不是一整页文字直接塞满。

例如：

1. `本周劳模：妈妈，没人能撼动。`
2. `爸爸，你不是没努力，你是努力得太像路过。`
3. `建议：周末做饭权暂时移交冠军。`

## 6. 控制台设计

### 6.1 总体气质

控制台像 `导演后台 / 节目控制室`。

这意味着：

- 左侧是总控导航
- 中部是节目参数
- 右侧是实时预览

### 6.2 重点页签

| 页签 | 设计语言 |
| --- | --- |
| 家庭成员 | 选手管理 |
| 家务规则 | 赛制配置 |
| 历史记录 | 回放中心 |
| 周报档案 | 赛季存档 |
| 偏好设置 | 总控台 |

### 6.3 毒舌强度控件

这套方案里最适合做 `LED 强度条`：

`温柔播报` → `阴阳怪气` → `公开处刑`

## 7. 动效系统

### 7.1 动效关键词

- 灯条扫过
- 数字翻牌
- 排名滑位
- 弹窗升起
- 波形脉冲

### 7.2 控制原则

虽然方案 B 允许更炸，但仍要遵守：

- 一屏主动画不超过 2 个
- 背景纹理动，主体不能乱跳
- 响应式时需要自动降级

## 8. 优势与风险

### 优势

- 记忆点极强
- 非常适合“公开处刑”调性
- AI 判决环节最有节目效果
- 打卡反馈会很爽

### 风险

- 很容易做过头
- 长期摆放会比方案 A 更累眼
- 控制台若沿用同样强度，可能显得太吵

## 9. 结论

如果你想让这个产品的第一印象就是“这个家有节目”，选它。  
如果你要长期摆客厅，我更建议它作为 `A 的强化参考`，而不是完整主方案。
