# 方案 A：公屏审判报

## 1. 方案定位

### 核心概念

把首页做成一张挂在客厅里的 `动态审判公告报`。  
它不是冷冰冰的数据屏，而是一块每天都在更新的家庭战绩海报。

### 风格关键词

- 编辑排版
- 公告栏
- 竞技榜单
- 家庭戏剧感
- 公共空间陈列感

### 适用判断

这套方案最适合当前产品。

原因是它同时满足：

- 横屏远距离可读
- 分数与人物一眼识别
- 有强个性但不至于吵
- 后续控制台也能延展

## 2. 视觉方向

### 2.1 整体氛围

像 `现代报纸头版 + 家庭积分榜 + 审判通告栏` 的混合体。

画面不是柔软圆润的卡片堆，而是：

- 粗边框
- 强标题
- 大数字
- 清晰分区
- 局部倾斜的通告贴条

### 2.2 配色系统

#### 主色板

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Ink Black | `#171717` | 主标题、边框、重点信息 |
| Warm Paper | `#F7F1E8` | 主背景 |
| Verdict Red | `#C63D2F` | 召唤 AI、危险操作、冠军强调 |
| Brass Gold | `#B8892D` | 冠军、勋章、重点数据 |
| Archive Blue | `#2E5B7B` | 核心家务、中性数据块 |
| Moss Green | `#58744D` | 举手之劳、轻任务 |
| Ash Gray | `#D7D0C6` | 次级背景、分隔区 |

#### 配色原则

- 用 `暖纸色` 保持家庭空间友好度
- 用 `红 + 金` 强化审判和榜单仪式感
- 用 `蓝 + 绿` 区分任务档位，避免全屏只剩危险红
- 禁止大面积发紫，避免普通互联网后台感

### 2.3 字体系统

| 角色 | 字体建议 | 用途 |
| --- | --- | --- |
| 标题 | `Archivo Expanded` / `Space Grotesk` | 产品名、排行名次、分数标题 |
| 正文 | `Noto Sans SC` | 所有中文正文、标签、日志 |
| 数据 | `IBM Plex Sans` / `Space Grotesk` | 分值、时间、统计数字 |

#### 字体气质

- 标题要有“印刷标题”的压迫感
- 正文必须稳，避免过于花哨导致长时间看累
- 数字要挺拔，远距离读分数时不能糊

## 3. 首页主打卡面板

### 3.1 信息架构

首页建议采用 `上中下三段式`：

1. 顶部：产品名、时间、三大入口、周状态摘要
2. 中部：成员打卡列阵 + 排行区
3. 底部：公开日志滚动带 + 待撤销提示 + 本周判词预告

### 3.2 页面草图

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 家庭无情裁判所     本周第4天 / 19:42     控制台 全屏 召唤AI裁判      │
├──────────────────────────────────────────────────────────────────────┤
│ 冠军：妈妈 28分      末位：爸爸 12分      本周已记录 49 次家务        │
├───────────────┬───────────────┬───────────────┬──────────────────────┤
│ 妈妈           │ 爸爸           │ 小宝           │ 排行 / 周审判预告      │
│ 28             │ 12             │ 16             │ 1 妈妈 28             │
│ +1 +3 +5       │ +1 +3 +5       │ +1 +3 +5       │ 2 小宝 16             │
│ 最近标签...     │ 最近标签...     │ 最近标签...     │ 3 爸爸 12             │
├───────────────┴───────────────┴───────────────┴──────────────────────┤
│ 公开日志：19:40 妈妈 完成 洗碗 +3 ｜ 19:38 爸爸 完成 倒垃圾 +1 ...      │
└──────────────────────────────────────────────────────────────────────┘
```

### 3.3 关键视觉组件

#### 顶部横幅

- 左侧是超大产品名
- 中间放 `本周状态条`
- 右侧是三个强按钮
- 可加入一条倾斜红色贴纸：`本周审判继续生效`

#### 成员卡片

每个成员不是普通 SaaS 卡片，而是 `公告报中的人物专栏`：

- 顶部有成员名和状态称号
- 中部是超大积分数字
- 下方是三枚巨型打卡按钮
- 底部是最近常用标签入口
- 积分变化时数字抖动，而不是卡片乱飞

#### 排行区

右侧单独留出一块 `排行榜与审判预告区`：

- 第一名金色栏
- 最后一名暗红或灰红栏
- 中间成员按层级收束
- 下半区展示“AI 今日拟判词”

### 3.4 任务按钮设计

| 按钮 | 视觉语言 | 感受 |
| --- | --- | --- |
| `+1 举手之劳` | 绿底黑字，边框清晰 | 轻快、随手记 |
| `+3 核心家务` | 蓝底白字，最稳重 | 日常主力项 |
| `+5 史诗恶战` | 红底白字，尺寸最大 | 有舞台感、像敲钟 |

#### 交互细节

- hover 不放大卡片本体，避免布局跳动
- 只做颜色压深、内阴影、边框高亮
- 点击后在成员分数旁冒出 `+1 / +3 / +5`
- 当前成员列可出现 400ms 的“记一笔”闪条

## 4. 标签选择浮层

### 4.1 形态建议

采用 `贴条式抽屉`，从成员列下方向上弹出。

不是居中小弹窗，因为那样会切断公共大屏的整体节奏。

### 4.2 结构

- 顶部显示当前成员 + 当前档位
- 首屏先给 `最近使用`
- 次屏给 `常用标签`
- 底部给 `更多标签`

### 4.3 视觉建议

- 像档案卡、标签贴纸、法庭卷宗分栏
- 每个标签像可点击的小通告牌
- 被点击后快速收起，并同步触发日志变化

## 5. AI 判决弹窗

### 5.1 设计目标

这一层必须是“秀场时刻”。

它要让全家有一种：

- “法官要宣判了”
- “今晚谁要被点名”
- “这次会不会开喷”

的期待感。

### 5.2 建议样式

- 背景使用深色半透明幕布
- 弹窗主体像一张 `盖了章的审判令`
- 顶部有红色标题条：`本周家庭判决书`
- 正文采用大段留白、强层级、打字机式逐段出现

### 5.3 内容结构排版

1. 本周总览
2. 冠军表彰
3. 末位调侃
4. 奖惩建议
5. 结语

#### 强化点

- 冠军用金章组件
- 末位用暗红批注框
- 奖惩建议用高亮贴条
- 风格强度在顶部角落展示当前模式，例如：
  `当前模式：毒舌强度 7 / 10`

## 6. 控制台设计

### 6.1 总体气质

控制台延续主屏语言，但收敛一些。

建议做成 `档案室 + 管理面板` 的感觉：

- 左侧目录像卷宗索引
- 右侧内容像大号登记表
- 高风险操作像红章确认区

### 6.2 页签建议

| 页签 | 表现方式 |
| --- | --- |
| 家庭成员 | 人员档案卡 |
| 家务规则 | 标签编目台 |
| 打卡历史 | 审判记录簿 |
| 周报档案 | 往期判决柜 |
| 数据分析 | 家庭走势报表 |
| 偏好设置 | 裁判风格面板 |

### 6.3 偏好设置重点

这一套里，`毒舌强度` 应做成最有辨识度的控件：

- 不是普通 slider
- 更像 `判罚刻度尺`
- 左边写 `讲道理`
- 右边写 `当众开喷`

## 7. 动效与反馈

### 7.1 动效原则

- 页面只允许 1 到 2 个主动画源
- 动画服务“记分”和“宣判”
- 不能全屏都在动

### 7.2 动效清单

- 分数变化：短促跳字
- 冠军变更：金色横条扫过
- 咸鱼落位：灰红标条落下
- AI 弹窗：幕布拉开 + 正文逐段打出
- 控制台开合：抽屉式横移

### 7.3 无障碍

- 提供 `prefers-reduced-motion`
- 关闭动效后，保留颜色和边框反馈

## 8. 优势与风险

### 优势

- 最适合做品牌识别
- 最适合客厅长期摆放
- 后续做周报档案很自然
- 容易做出“家庭公共装置”的感觉

### 风险

- 如果标题和边框太多，容易显得信息拥挤
- 需要精细控制留白，否则会像海报墙

## 9. 结论

如果你只选一套来做前端，我建议优先做这套。  
它是当前产品最平衡、最像“家庭无情裁判所”的方案。
