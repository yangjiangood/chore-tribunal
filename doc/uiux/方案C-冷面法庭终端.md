# 方案 C：冷面法庭终端

## 1. 方案定位

### 核心概念

把产品做成一台 `现代法庭信息终端`。  
它更像“正式宣判设备”，而不是综艺或海报。

### 风格关键词

- 法庭终端
- 公民服务机
- 克制权威
- 数据审判台
- 稳定专业

### 适用判断

这套方案适合：

- 希望产品更稳、更成熟
- 后续控制台和数据页比首页更重要
- 不想让界面过于娱乐化

## 2. 视觉方向

### 2.1 整体氛围

像 `轻量法务终端 + 家庭数据站 + 公共服务设备`。

它保留“裁判所”的秩序感，但弱化综艺感。

### 2.2 配色系统

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Court Slate | `#233142` | 主文本、重点边框 |
| Stone White | `#F5F3EF` | 主背景 |
| Verdict Amber | `#C58B1F` | 冠军、重点、警示中高亮 |
| Record Red | `#9F3A32` | 负向提示、危险操作 |
| Registry Blue | `#3F6E8C` | 核心功能块 |
| Olive Gray | `#70806B` | 次级状态、辅助背景 |
| Dust Line | `#D8D1C6` | 分隔线 |

### 2.3 字体系统

| 角色 | 字体建议 | 用途 |
| --- | --- | --- |
| 标题 | `Manrope` / `Public Sans` | 法庭感标题、导航 |
| 正文 | `Noto Sans SC` | 中文正文 |
| 数据 | `IBM Plex Sans` | 数字、时间、统计 |

#### 字体气质

- 现代、克制、冷静
- 不走夸张海报字
- 数据阅读效率优先

## 3. 首页主打卡面板

### 3.1 页面结构

建议使用 `秩序化仪表盘布局`：

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 家庭无情裁判所 / 今日状态 / 控制台 / 全屏 / 召唤AI                    │
├──────────────────────────────────────────────────────────────────────┤
│ 本周概览：总分 / 核心家务占比 / 活跃成员 / 待确认事件                 │
├──────────────────────┬───────────────────────────────┬───────────────┤
│ 排行榜                │ 成员打卡主区                    │ 审判摘要        │
│ 名次 / 变化 / 连续状态  │ 2-5 名成员列阵                  │ 风格强度 / 预告  │
├──────────────────────┴───────────────────────────────┴───────────────┤
│ 公开日志 / 系统提示 / 撤销区                                              │
└──────────────────────────────────────────────────────────────────────┘
```

### 3.2 组件表现

#### 顶部区

- 更像正式终端页头
- 产品名不过分夸张
- 状态信息用细分栏表达
- 三大入口维持统一矩形按钮

#### 成员列

成员列像 `案件执行席位`：

- 成员名
- 当前积分
- 本周状态标签
- 三档操作按钮

与 A、B 相比，这套更重秩序，不刻意制造视觉冲突。

#### 排行榜

排行采用简洁表格化样式：

- 名次
- 成员
- 分数
- 走势

冠军用琥珀高亮，垫底用暗红标记。

## 4. 标签选择浮层

### 4.1 形态

采用 `右侧信息抽屉` 或 `下拉式操作面板`。

优势是：

- 更稳定
- 不抢首页注意力
- 更像终端的二级操作区

### 4.2 内容组织

- 当前档位
- 最近使用
- 常用标签
- 全部标签

每个标签统一为规整按钮，不做太多戏剧化造型。

## 5. AI 判决弹窗

### 5.1 设计目标

在这套方案里，AI 判决像 `电子裁定书`。

它依然要有仪式感，但不是舞台感，而是“正式下发结果”的感觉。

### 5.2 表现建议

- 白底或石色底面板
- 左上角红章或裁定标记
- 顶部展示人设和强度
- 正文分为结构清晰的 5 段

### 5.3 风格优势

即使毒舌强度调高，也不会显得太像闹剧。  
更适合“狠归狠，但页面还是稳”的视觉策略。

## 6. 控制台设计

### 6.1 这套方案最强的地方

控制台会非常适合用这套语言。

尤其这些模块：

- 成员管理
- 标签规则
- 打卡历史
- 数据分析
- 周报档案

### 6.2 设计语言

- 左侧树状导航
- 右侧大内容区
- 顶部筛选条
- 表格、统计卡、时间轴并存

### 6.3 偏好设置

风格控件建议做成 `分档式切换`，而不是强综艺化滑杆。

例如：

- `克制`
- `毒舌`
- `开喷`

## 7. 动效系统

### 7.1 动效关键词

- 状态淡入
- 列表滑位
- 面板展开
- 数字轻微翻动
- 弹窗稳态出现

### 7.2 控制原则

- 动效服务信息理解
- 不制造戏剧化大动势
- 适合长期运行

## 8. 优势与风险

### 优势

- 最稳
- 最适合扩展管理后台
- 数据分析页最容易做专业
- 不容易过时

### 风险

- 首页第一眼冲击力不如 A、B
- “无情裁判所”的趣味性需要靠文案补足

## 9. 结论

如果你更看重长线产品化和控制台专业度，这套很稳。  
如果你更看重首页的品牌记忆点，它更适合作为 `控制台语言` 或 `A 的次级参考`。
